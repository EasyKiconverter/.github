# EasyKiConverter

EasyKiConverter is an open-source Qt 6/C++17 desktop and CLI tool for converting LCSC and EasyEDA component data into electronic design automation libraries.

- [Main repository](https://github.com/EasyKiconverter/EasyKiConverter)
- [Documentation](https://easykiconverter.github.io/EasyKiConverter/)
- [Releases](https://github.com/EasyKiconverter/EasyKiConverter/releases)
- [Discussions](https://github.com/EasyKiconverter/EasyKiConverter/discussions)
- [Contributing](https://github.com/EasyKiconverter/EasyKiConverter/blob/master/docs/developer/CONTRIBUTING_en.md)

The project currently provides KiCad export and active development support for Altium and Xpedition library formats through a shared intermediate representation. Packages are published for supported Windows, Linux, and macOS architectures on the Releases page.
